# 🛰️ Featured Work

### ☁️ SkyGuard AI

> **Turning weather telemetry into trustworthy data.**

An intelligent anomaly-detection system for Automatic Weather Stations that analyzes temperature, atmospheric pressure and relative humidity to identify abnormal sensor behavior.

**Built for:** Smart India Hackathon 2026 · `SIH26073`

`Python` `Scikit-learn` `Machine Learning` `Java` `Spring Boot` `Angular` `TimescaleDB` `Kafka`

### 🌱 SarthiAI

A voice-first, offline-capable AI form companion designed to help users understand and navigate government forms using document-grounded assistance, multilingual interaction and accessibility-first design.

**Built for:** AI for Bharat · Amazon Hack2Skill

`AI` `LLM` `RAG` `AWS` `Voice AI` `OCR` `TypeScript`
